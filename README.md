## 📊 Projects

### 1. Salary Prediction Model
**File:** `salary_prediction_analysis.ipynb`

- Analyzed 6,700+ salary records using Python and Scikit-learn
- Cleaned data by handling missing values (mean imputation)
- Removed 5,956 duplicate rows for data quality
- Built linear regression model: `Salary = 4,797 × (Years of Experience) + 72,508`
- Achieved R² = 0.60 and Pearson correlation = 0.78
- Performed cross-validation with training sizes 30% - 80%
- Identified overfitting patterns for model improvement

**Visualizations:**
- Boxplots for outlier detection
- Scatter plots for relationship analysis
- Histograms for distribution analysis
- Regression line visualization

---

### 2. Social Network Ads Classification
**File:** `social_network_ads_classification.ipynb`

- Built K-Nearest Neighbors (KNN) classifier to predict purchase behavior
- Features: Age and Estimated Salary
- Preprocessing: StandardScaler for feature normalization
- Train/Test split: 75% / 25%

**Model Performance:**
- Accuracy: **87%**
- Precision: **0.83**
- Recall: **0.83**
- F1-Score: **0.83**
- AUC: **0.92**
